# 九州武侠 · 演武场 V1

独立二维战斗试玩，入口 `duel/index.html`。不引用旧版人物模型或战斗模块。

- 人物：一张 4×4 动作图集，待机、出掌、挥剑、受击各四帧；程序直接读取格子。
- 降龙十八掌：龙形图片按纵向条带做起伏，蓄力、出掌、冲击、命中反馈。
- 万剑归宗：100 道可视剑气，凝聚、分批发射与十次连续伤害。
- 普通出掌、对手反击、双方血量、重置切磋。
- 手机按钮和电脑 1/2/3 快捷键；音效需点击开启。
- PWA 主屏幕入口与素材缓存，首次联网完整加载后支持缓存范围内离线启动。缓存可能被浏览器清理。

## 运行

仓库根目录执行 `python -m http.server 8765`，打开 `http://localhost:8765/duel/`。

## 美术来源与限制

素材来自当前工作目录中的生成图片；人物图集本轮通过内置 imagegen 编辑工具做了边缘清理尝试。提示词：保留同一青白衣武侠、4×4等格、站立/出掌/挥剑/受击四行，真实透明背景，统一角色尺度与落脚点，移除边缘杂色、保留画风。

人物仅四帧每动作，部分帧细节存在差异。当前不是完整角色扮演游戏，不含旧版地图、成长、剧情和存档；主角与对手复用同一图集并镜像着色。后续根据实际试玩改动作、美术和特效。
