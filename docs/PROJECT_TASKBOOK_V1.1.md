# 《九州武侠》正式项目任务书 V1.1

## 1. 项目定位

类型：单机动态武侠大世界 + 角色成长 + 江湖模拟 + 动态剧情。

玩家不是进入一本本小说副本，而是出生在一个融合后的九州世界。原著人物、门派、朝廷、战争、恩怨与剧情同时存在并持续运行。

## 2. 最高原则

### 2.1 零内购

禁止充值、VIP、月卡、战令、抽卡、付费武学、付费神兵、付费属性和商城战力。

成长只能来自：出身、天赋/外挂、拜师、修炼、实战、奇遇、探索、人际关系、门派传承、江湖任务、秘籍、神兵、抢夺、交换、参悟与世界事件。

### 2.2 真正的活江湖

玩家不行动时，世界仍然运行。NPC 可以移动、修炼、交友、结仇、受伤、死亡、失踪、收徒、背叛、争夺秘籍、参与战争和势力斗争。

原著剧情是“高概率历史事件链”，不是强制脚本。关键人物提前死亡或事件条件改变后，历史必须重新推演。

### 2.3 跨作品战力不平权

判定优先级：

实际战斗表现 > 明确设定 > 旁白描述 > 江湖名声 > 人物地位。

禁止因为人物在本作中是“天下第一”就强行抬到其他作品的高武层级。传统金庸绝顶可以被《风云》高武人物明显压制，甚至形成无法正常对战的规格差。

### 2.4 《风云》范围

当前项目只采用《风云》第一部、第二部，不扩展第三部。

世界力量路线允许从传统武侠逐步进入高武、超高武，但不无限向后膨胀。

### 2.5 战斗表现

禁止采用纯文字互扣血作为正式战斗表现。

战斗底层可以是时间轴/半回合规则，但视觉必须支持人物位移、冲刺、腾空、受击、击退、击飞、残影、剑气、刀光、掌风、真气、闪电、火焰、冰霜、粒子、Hit Stop、震屏、镜头缩放、伤害数字和招式大字。

## 4. 世界地图结构

最高层采用国家/国域，而不是“江南、中原、荆襄”作为一级地图。

结构：

天下列国图 → 国家/国域 → 地区 → 地点 → 场景 → 人物/事件/行动。

暂定一级世界：

- 大唐
- 大宋
- 大明
- 大清
- 大理
- 辽
- 西夏
- 蒙古
- 神州
- 西域诸国
- 海外

这是架空融合时代，不严格服从真实历史年代。

大唐主要承载不良人体系；大宋承载射雕、神雕及部分天龙；大明承载笑傲与天下第一；大清承载鹿鼎记；神州承载风云。

## 5. 角色创建

基础属性共七项：

- 根骨
- 悟性
- 体魄
- 身法
- 定力
- 福缘
- 魅力

支持随机、重新随机和后续自定义模式。

普通初始属性建议范围 35–75；极少数自然随机可到 76–90；90 以上主要依赖特殊出身、唯一外挂或先天体质。

## 8. 战力系统

玩家可看到模糊江湖评价，但开发内部使用连续规格指标与多维属性，不以简单境界决定胜负。

内部关键维度：速度、输出、防御、功力、武学技巧、特殊能力。

必须区分同一人物的不同时期和状态。例如早期聂风、第一部后期聂风、第二部聂风是不同战斗实体；无名、步惊云等同理。

传统武侠天花板到风云高武之间必须保留多个真实过渡层。早期聂风仍明显弱于雄霸；雄霸又明显弱于巅峰无名；第一部无名与第二部无名不同；第二部高峰无名仍低于完整帝释天；当前项目将笑三笑作为第二部范围内的最高级世界锚点之一。

## 9. NPC 模型

关键 NPC 至少记录：身份、年龄、健康、性格、武功、装备、关系、仇恨、好感、当前位置、当前行动、短期目标、长期目标、所属势力、政治立场、隐藏信息。

AI 分层：

- S 级：长期战略目标，能推动势力/国家级事件。
- A 级：明确个人目标与长期行动。
- B 级：按日程和事件行动。
- 普通 NPC：轻量规则，不运行完整人生模拟。

## 10. 武学系统

分类至少覆盖内功、拳、掌、指、剑、刀、枪、棍、暗器、轻功、横练、音功、奇门、医术、毒术、特殊功法。

高阶武学必须拥有学习条件、属性要求、内力性质、招式、熟练度、理解度、实战理解、搭配、克制、特殊效果、修炼风险和表现模板。

绝学不能在普通商店直接购买。获得方式包括拜师、门派传承、奇遇、偷学、抢夺、探索、NPC 赠送、交换、残篇组合、武学推演与世界事件。

## 11. 工程结构

禁止再出现类似巨型单核心 JS 持续膨胀的问题。

建议模块：

- `core/`
- `player/`
- `world/`
- `npc/`
- `faction/`
- `martial/`
- `combat/`
- `combat-render/`
- `event/`
- `item/`
- `save/`
- `data/`
- `ui/`

逻辑与表现分离。战斗渲染层独立管理 renderer、animation、particles、camera、skill-fx。

所有国家、地点、NPC、势力、武学、装备、秘籍、事件使用稳定 ID。从第一版开始支持 save schema、迁移、自动/手动存档与多档位。

## 12. 开发阶段

### Phase 0

规则基线：国家、属性、出身、外挂、战力、势力、NPC 模型、武学基础规则。

### Phase 1

最小可玩大明。

### Phase 2

角色成长闭环。

### Phase 3

正式 Canvas 动态战斗。

### Phase 4

动态 NPC 与世界状态。

### Phase 5

动态事件链。

### Phase 6+

依次扩展大宋、大唐、传统武侠大世界，之后再进入神州与风云第二部高武内容。

## 13. 正式 V0.1 验收

必须完整通过：

创建人物 → 随机属性 → 选择出身 → 选择唯一外挂/无外挂 → 进入大明 → 地图移动 → 与 NPC 互动 → 拜师/获得武功 → 装备兵器 → 动态战斗 → 获得战利品/秘籍 → 世界时间推进 → NPC 后台行动 → 动态事件发生 → 保存 → 重新读取且世界状态一致。

只有完整链路通过，才允许称为 V0.1 可玩版完成。
