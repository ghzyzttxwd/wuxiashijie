# 九州武侠工程架构

从第一天禁止巨型单文件。逻辑、数据、表现、存档分离。

- `src/core/`：游戏循环、时钟、随机数、全局状态
- `src/player/`：玩家角色、属性、出身、外挂、成长
- `src/world/`：国家、地区、地点、世界时间与旅行
- `src/npc/`：NPC实体、AI、日程、关系
- `src/faction/`：门派、朝廷组织、外交和势力状态
- `src/martial/`：武学、学习、熟练、内功、招式
- `src/combat/`：战斗规则、时间轴、伤害、战斗AI
- `src/combat-render/`：Canvas渲染、动画、粒子、镜头、技能特效
- `src/event/`：动态事件、剧情链、传闻
- `src/item/`：物品、装备、秘籍
- `src/save/`：多档位、schema、迁移
- `src/data/`：纯数据，按类别和作品继续拆分
- `src/ui/`：页面和面板，只负责交互显示

硬规则：单个业务文件原则上不得无限膨胀；数据优先拆到 `src/data/*`，核心系统通过稳定ID引用数据。
