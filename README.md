# 九州武侠（wuxiashijie）

融合武侠动态大世界单机游戏。

## 公开试玩

- 当前大明 V0.1 公开试玩：`https://ghzyzttxwd.github.io/wuxiashijie/`
- M10 已通过：Node 回归、真实 Chromium 视觉回归、确定性战斗命中帧、GitHub Pages 官方部署与公网 HTTP smoke 均已验证。
- 当前阶段：**M11 玩家本人长期试玩驱动打磨**。后续优先处理真实试玩中遇到的 bug、交互不爽、断链和表现问题，不因机器人觉得难、慢或不平衡而自动削弱游戏。

## 项目定位

- 单机、零内购、零充值、零 VIP、零抽卡。
- 玩家不是任何原著主角，而是拥有独立出身、属性和唯一外挂的自建角色。
- 世界按照“国家/国域 → 地区 → 地点 → 场景”组织，而不是把不同作品做成副本菜单。
- NPC、门派、王朝、战争和原著事件在玩家不参与时也会继续运行。
- 原著剧情是高概率历史事件链，不是不可改变的固定剧本。
- 跨作品战力不做平权，只依据原作实际表现与明确设定；允许不同作品之间存在巨大规格差。
- 《风云》内容目前只采用第一部、第二部，不扩展第三部。
- 战斗必须有真正动态表现：位移、出招、受击、击退、残影、剑气/掌风、粒子、Hit Stop、震屏、镜头反馈等；禁止退回纯文字互扣血。

## 当前开发策略

大明 V0.1 的第一条完整可玩链已经建立并公开发布。现阶段不继续为了“系统数量”盲目扩张，而是进入真实玩家试玩打磨；确认核心体验稳定后，再扩展大宋、大唐、神州等世界内容。

V0.1 当前底座：

1. 七项基础属性。
2. 19 种出身。
3. 15 个唯一外挂（可不选）。
4. 大明分层地图。
5. 首批 20 个核心动态 NPC。
6. 首批 30 门武学。
7. Canvas 动态战斗：真实接敌位移、残影、武器轨迹、命中闪白、击退、粒子、镜头反馈。
8. 福威镖局、五岳并派、护龙山庄—东厂三条动态事件链。
9. NPC 同场景交互、关系记录与持久化。
10. 多档存档、稳定 ID、存档迁移和完整闭环回归。
11. GitHub Pages 公开试玩与公网 smoke 验收。

## 核心开发原则

**先能玩，再扩世界；真实玩家反馈优先于机器人平衡判断。**

代码完成不等于版本完成。任何新功能都必须继续守住“创建人物 → 进入世界 → 旅行/NPC → 学武 → 动画战斗 → 动态事件 → 世界推进 → 保存/读取”的完整用户链路；M11 期间只根据真实试玩暴露的问题改，不为了测试机器人方便擅自降低难度或成长门槛。
