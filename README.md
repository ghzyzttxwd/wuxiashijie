# 九州武侠（wuxiashijie）

融合武侠动态大世界单机游戏。

## 项目定位

- 单机、零内购、零充值、零 VIP、零抽卡。
- 玩家不是任何原著主角，而是拥有独立出身、属性和唯一外挂的自建角色。
- 世界按照“国家/国域 → 地区 → 地点 → 场景”组织，而不是把不同作品做成副本菜单。
- NPC、门派、王朝、战争和原著事件在玩家不参与时也会继续运行。
- 原著剧情是高概率历史事件链，不是不可改变的固定剧本。
- 跨作品战力不做平权，只依据原作实际表现与明确设定；允许不同作品之间存在巨大规格差。
- 《风云》内容目前只采用第一部、第二部，不扩展第三部。
- 战斗必须有真正动态表现：位移、出招、受击、击退、残影、剑气/掌风、粒子、Hit Stop、震屏、镜头反馈等；禁止退回纯文字互扣血。

## 当前开发策略

先做一个真正可玩的“大明 V0.1”，验证核心底座，再扩展大宋、大唐、神州等世界内容。

V0.1 重点：

1. 七项基础属性。
2. 19 种出身。
3. 15 个唯一外挂（可不选）。
4. 大明分层地图。
5. 首批 20 个核心动态 NPC。
6. 首批 30 门武学。
7. Canvas 动态战斗原型。
8. 福威镖局、五岳并派、护龙山庄—东厂三条动态事件链。
9. 多档存档与稳定 ID。

## 核心开发原则

**先能玩，再扩世界。**

任何阶段不得因为内容规模扩大而推迟完整可玩链路。代码完成不等于版本完成；必须实际验证“创建人物 → 进入世界 → 学武 → 动画战斗 → 动态事件 → 保存/读取”的完整用户链路。
