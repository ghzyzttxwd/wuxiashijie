# 数据层规则

`src/data/` 只保存声明式数据，不保存游戏流程逻辑。

## 分类
- `attributes.js`：七项基础属性定义
- `origins.js`：V0.1 出身数据；数量继续增长时再按阶层拆分
- `talents.js`：唯一外挂数据；数量继续增长时再拆分
- `countries/`：国家/政权
- `locations/`：地区/地点/场景
- `npcs/`：NPC，按国家与作品拆
- `factions/`：门派、帮会、朝廷机构
- `martial/`：武学，按作品/体系拆
- `items/`：装备、秘籍、药品等
- `events/`：事件定义
- `power/`：跨作品战力锚点与人物阶段版本

## 硬规则
1. 使用稳定 ID 互相引用，不通过中文名称做主键。
2. 数据文件原则上按领域、国家、作品继续细分。
3. 单文件明显膨胀时必须拆分，禁止出现类似旧项目几十万字节核心文件。
4. 逻辑代码不得复制进数据文件；Canvas表现不得写进战斗规则文件。
